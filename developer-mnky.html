Monkey Move (MNKY)

Aim

To command the monkey using only your voice or the keypad. Guide the monkey to the end of the level.

Look out for

Monkey is fine tuned to my voice so you may find it hard to control the monkey at first. The trick is to use very short and high pitched sounds.

It’s using

It is using the bee engine and the mic input. It measures the pattern of sound coming in through the microphone every 200 ms and tries to match the pattern to the ones already stored in memory by me. If the pattern matches then the corresponding action is taken otherwise the pattern is ignored.

History

Engine reused from BZB and added voice pattern engine.

Controls

short “ooh” = jump

Short “ooh” (while jumping) = double jump

long “ooh” (while jumping) = air roll

long “ooh” (while standing) = ground slam

long “ooh” (while walking or running) = stop

short “ooh” “ooh” (whilst stopped) = walk

short “ooh” “ooh” (whilst walking) = run

short “ooh” “ooh” (whilst running) = walk

short “ooh” then long “ooh” = turn around

Ground slam can be used to break brick blocks underneath monkey.

Air roll can be used to break brick blocks to the side of monkey in the direction that monkey is travelling in.

Rules

Walk ontop a yellow flower to save the game.

Walk ontop of a red flower to finish the level.

Move over bananas to collect them.

Get Started

Load up monkey-voice.swf

Click the start button

Click “allow” to turn on the mic.

Click the long black button with a red outline to load the level and start the game.
