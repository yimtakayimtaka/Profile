Excel - Data Cleaning & Analysis

This project replicates our end-to-end Python data pipeline natively within Microsoft Excel. We load student_toclean.csv, perform integrity checks, clean string anomalies and missing values, map class word levels into numeric integers using Excel formulas, aggregate student performance across class levels and gender via Pivot Tables, and generate native line and bar charts to answer whether gender relates to marks and how that changes with age.

Step 1: Data Import & Initial Inspection

We load student_toclean.csv into Excel via Data > Get Data > From Text/CSV. For automation and environment setup via PowerShell, we use the following setup commands: 

# PowerShell: Verify CSV file presence and inspect first few rows
Get-Content -Path "student_toclean.csv" -TotalCount 5

# Launch Excel with the target CSV dataset
Start-Process "excel.exe" "student_toclean.csv"

Step 2: Data Cleaning & Integrity Verification (Power Query)

In Power Query Editor (Transform Data), we inspect nulls, remove duplicates, trim whitespace, and sanitize text columns using the following M formula steps: 

// Power Query M Code for Data Hygiene & Cleaning
let
    Source = Csv.Document(File.Contents("C:\Data\student_toclean.csv"), [Delimiter=",", Columns=5, Encoding=65001, QuoteStyle=QuoteStyle.Csv]),
    PromotedHeaders = Table.PromoteHeaders(Source, [PromoteAllScalars=true]),
    
    // Remove rows where critical columns are null
    RemovedNulls = Table.SelectRows(PromotedHeaders, each ([name] <> null and [class] <> null and [mark] <> null and [gender] <> null)),
    
    // Trim whitespace and standardize case formatting
    TrimmedNames = Table.TransformColumns(RemovedNulls,{{"name", Text.Trim, type text}, {"gender", each Text.Lower(Text.Trim(_)), type text}})
in
    TrimmedNames

Step 3: Class Level Mapping (Excel Formulas)

To convert word-based class levels (e.g., "Three", "Four", and typos like "Fifth") into numeric integers, we insert a calculated column class_level using nested SWITCH or IFS formulas in cell F2: 

=SWITCH(TRIM(C2), 
    "One", 1, 
    "Two", 2, 
    "Three", 3, 
    "Four", 4, 
    "Five", 5, 
    "Fifth", 5, 
    "Six", 6, 
    "Seven", 7, 
    "Eight", 8, 
    "Nine", 9, 
    "Ten", 10, 
    VALUE(C2)
)

Step 4: Querying Performance (Pivot Table Aggregation)

We load the cleaned table into the Data Model and build a Pivot Table to compute average performance grouped by class_level and gender. 

PivotTable Fields Configuration:
------------------------------------------
• Rows:     class_level
• Columns:  gender
• Values:   mark (Summarized by: Average, Formatted as 0.00)

Excel CUBE / GETPIVOTDATA formula representation:
=GETPIVOTDATA("mark", $A$3, "class_level", 3, "gender", "female")

Step 5: Visualizing Performance Trends (Native Excel Charts)

Highlight the Pivot Table range and navigate to Insert > Recommended Charts > Line Chart with Markers (or Clustered Column) to generate the analytical chart matching our Python Seaborn trend visualization. 

Chart Customization Steps in Excel:
------------------------------------------
1. Select PivotChart -> Line with Markers.
2. Chart Title: "Student Performance Trends by Class Level and Gender".
3. Axis Titles: X-Axis = "Class Level", Y-Axis = "Average Mark".
4. Color Palette: Dark mode Slate & Blue theme matching HAQmedia 3D design standards.
